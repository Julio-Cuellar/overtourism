07Funciones (comandos y consultas)

Los comandos viajan como variantes de ComandoInput en el par de plataforma prepararComando / confirmarComando (D-55).

15Documentación del código con JavaDoc D-142 ACEPTADA

  
Pedido del usuario: documentar el código con JavaDoc «para no batallar a la hora de encontrar errores». La idea es que un código de error en el registro lleve directo a su regla en este diseño.

  
    
    
  1. Cada clase, record e interfaz pública dice qué representa y, si es agregado, su ciclo de estados.
    2. 
    
  2. Cada método público de VentasApi y CajaApi lleva descripción, @param, @return y un @throws o código de error por cada fallo de dominio.
    3. 
    
  3. Cada método cita su ID de función (VF-10, CF-12) y las reglas que aplica (VT-04, CJ-07). Cada código de error cita la regla que lo produce.
    4. 
    
  4. Los records de eventos documentan cada campo de datos y cuándo se publican.
    5. 
    
  5. Todo campo o parámetro de dinero indica escala y redondeo.
    6. 
    
  6. mvn javadoc:javadoc sin advertencias entra en la verificación de cada fase.
    7.
